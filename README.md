# 午休模式

菜单栏里的午睡开关。开始后，外接显示器的白点降到原来的 25%。结束或退出后，曲线回到进入午休前的样子。

适合合盖接一块外接屏：屏幕还亮着，但白被压暗，方便午休。改的是这块屏的白点曲线，不是显示器背光。

## 安装

1. 从 [Releases](https://github.com/l0000000lita/napmode/releases) 下载 `NapMode.dmg`。
2. 打开镜像，把「午休模式」拖进「应用程序」。
3. 打开「午休模式」。菜单栏会出现「午休」。

第一次打开如果系统拦住了：打开「系统设置 → 隐私与安全性」，点「仍要打开」。

## 使用

点「退出」或系统正常结束程序时，会先结束午休，再尝试把外接屏恢复。恢复不了也不会卡住退出。

| 菜单 | 作用 |
| --- | --- |
| 开始午休 | 外接屏白点降到 25% |
| 结束午休 | 恢复进入午休前的曲线 |
| 重试恢复 | 午休已经结束，但还有屏幕没写回。只恢复，不再压暗 |
| 退出 | 先结束午休并尝试恢复，再退出程序 |

午休开着时，菜单栏显示「午休中」。强制退出时程序来不及写回。记录如果仍是午休中，下次打开会继续压暗。

菜单显示「待恢复」时，午休已经结束。点「重试恢复」，或退出后重新打开，才会再尝试写回。程序开着时接回显示器，不会自动写回，也不会再次压暗。这条曲线对应结束午休前的设置；如果之后改过描述文件或校准，写回会盖掉现在的设置。

程序没在运行时，没法在显示器重新接上的那一刻自动恢复。不要同时开两个「午休模式」。

如果结束午休后恢复记录写不进磁盘，菜单会停在「待恢复」，不会继续压暗。这还不算完全成功。进程若在记录更新前结束，下次打开仍可能读到旧的午休记录并再次压暗。

程序在午休中每 2 秒检查一次，避免系统把曲线改回去。

只处理外接显示器。MacBook 内置屏保持原样。

## 从源码运行

需要 macOS 13 或更新版本，以及 Swift 命令行工具。

```bash
swift run NapCoreTests
./scripts/build-app.sh
open NapMode.app
```

`swift run NapCoreTests -- --live` 会短暂压低当前外接屏的白点，然后恢复。
